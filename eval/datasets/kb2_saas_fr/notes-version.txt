Nuvio - Notes de version 4.2

La version 4.2 a été publiée le 8 septembre 2026. La nouvelle vue Charge de travail affiche les tâches assignées à chaque membre par semaine. Les tâches récurrentes peuvent désormais se répéter chaque jour ouvré. Les champs personnalisés acceptent maintenant les formules simples comme SOMME et MOYENNE. Le mode sombre est disponible sur le web et sur mobile. L'export PDF d'un diagramme de Gantt conserve désormais les couleurs des tâches. La recherche trouve maintenant le texte contenu dans les pièces jointes PDF. Corrigé : les rappels d'échéance n'étaient pas envoyés pour les tâches sans heure. Corrigé : la synchronisation Google Drive dupliquait certains fichiers renommés. La prise en charge d'Internet Explorer 11 est définitivement arrêtée. La version 4.3 prévue en décembre 2026 apportera les tableaux de bord partagés. L'application de bureau pour macOS et Windows passe en version 2.0 avec les notifications natives. Le temps de chargement des grands tableaux Kanban a été réduit de 40 %. Les administrateurs peuvent exporter la liste des membres au format CSV. Les dépendances entre tâches signalent désormais les conflits de dates en rouge.
